# Знакомьтесь - это проект "Менеджер задач"!

Логика нашего приложения будет подразумевать работу с данными, для хранения которых нужно будет использовать базу данных. Взаимодействие с данными мы будем осуществлять с помощью Spring Data JPA.

### Приложение задеплоено на Render: https://java-project-99-eoy7.onrender.com

**Сборка:**
```java
make build
```
**Тест:**
```java
make test
```
**Sonar:**
```java
make sonar
```
**CheckStyle:**
```java
make lint
```
**Запуск:**
```java
make run
```
