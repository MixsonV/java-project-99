# Знакомьтесь - это проект "Менеджер задач"!

Логика нашего приложения подразумевает работу с данными, для хранения которых используется база данных. Взаимодействие с данными осуществляется с помощью Spring Data JPA.

### Приложение задеплоено на Render: https://java-project-99-eoy7.onrender.com
**Аккаунт администратора:**

    - Логин: hexlet@example.com
    - Пароль: qwerty

**CRUD задачи:**

      - Создать задачи
      - Назначить исполнителей
      - Указать статус задач
      - Структурировать задачи метками

**Сборка:**
```java
make build
```
**Тест:**
```java
make test
```
**Sonar:**
```java
make sonar
```
**CheckStyle:**
```java
make lint
```
**Запуск:**
```java
make run
```
